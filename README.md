# Quiz & Notes

A Flutter app for organizing learning material as **Subjects → Notes / Quizzes**.
Notes are Markdown with images; quizzes support single/multi-choice, true/false
and self-graded short answers. Quizzes and notes can be generated by AI
(Gemini, OpenAI, Anthropic or any OpenAI-compatible endpoint) from pasted text or
a YouTube video, using **your own API key** (stored only on the device).
Data is stored offline-first in Hive CE and synced to Supabase, which also
provides auth and view-only sharing between users.

Platforms: Android, Web, Linux, Windows, macOS.

Developer contracts (models, interfaces, providers, routes): [docs/CONTRACTS.md](docs/CONTRACTS.md).

## Requirements

- Flutter **stable** (3.47 or newer) — <https://docs.flutter.dev/get-started/install>
- A Supabase project — <https://supabase.com> (free tier is fine)
- Optional: [Supabase CLI](https://supabase.com/docs/guides/cli) to apply
  migrations and run the RLS tests (needs Docker for `supabase test db`)
- Platform toolchains as needed: Android SDK / Android Studio, Visual Studio
  (Windows), Xcode (macOS), `clang cmake ninja-build pkg-config libgtk-3-dev
  libsecret-1-dev` (Linux; `libsecret` is needed by `flutter_secure_storage`)

## Setup

```sh
flutter pub get
cp env.example.json env.json   # then fill in your values (env.json is git-ignored)
```

`env.json`:

```json
{
  "SUPABASE_URL": "https://YOUR-PROJECT-REF.supabase.co",
  "SUPABASE_ANON_KEY": "YOUR-ANON-OR-PUBLISHABLE-KEY"
}
```

Find both under Supabase dashboard → Project Settings → API. The anon /
publishable key is safe in the client; all data is protected by Row Level
Security.

### Database

Migrations live in `supabase/migrations/`, RLS tests in `supabase/tests/`.

With the Supabase CLI:

```sh
supabase login
supabase link --project-ref YOUR-PROJECT-REF
supabase db push            # applies supabase/migrations/*.sql
```

Without the CLI, run each migration file in order in the dashboard SQL editor.

Local development stack (optional):

```sh
supabase start              # local Postgres/Auth/Storage in Docker
supabase db reset           # apply migrations to the local stack
supabase test db            # run pgTAP RLS tests
```

In Supabase → Authentication → URL configuration, add your app URLs (e.g.
`http://localhost:3000`) as redirect URLs for email confirmation / password
reset.

## Run

```sh
# Web (fixed port so it matches the Supabase redirect URL)
flutter run -d chrome --web-port 3000 --dart-define-from-file=env.json

# Android (emulator or device)
flutter run -d android --dart-define-from-file=env.json

# Desktop
flutter run -d linux   --dart-define-from-file=env.json
flutter run -d windows --dart-define-from-file=env.json
flutter run -d macos   --dart-define-from-file=env.json
```

Release builds take the same flag, e.g.
`flutter build web --dart-define-from-file=env.json`. Without it the app shows a
"Supabase is not configured" screen.

## AI providers

Open **Settings** in the app, choose a provider, paste your API key, and pick a
model. Keys are kept in the platform secure storage (Keychain / Keystore /
libsecret / browser storage on web) and are never uploaded. For OpenRouter,
Ollama, etc. choose *OpenAI-compatible* and set the base URL.

YouTube: Gemini receives the video URL directly; other providers use the
video's captions fetched on the device (videos without captions can't be used;
on web, caption fetching may be blocked by CORS — use Gemini there).
